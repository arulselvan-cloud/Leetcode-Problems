Question:
You are given an integer array coins representing coins of different denominations and an integer amount representing a total amount of money.

Return the fewest number of coins that you need to make up that amount. If that amount of money cannot be made up by any combination of the coins, return -1.

You may assume that you have an infinite number of each kind of coin.

 

Example 1:

Input: coins = [1,2,5], amount = 11
Output: 3
Explanation: 11 = 5 + 5 + 1
Example 2:

Input: coins = [2], amount = 3
Output: -1
Example 3:

Input: coins = [1], amount = 0
Output: 0
 

Constraints:

1 <= coins.length <= 12
1 <= coins[i] <= 231 - 1
0 <= amount <= 104

C++ Solution:

class Solution {
public:
    int coinChange(vector<int>& coins, int amount) {
        vector<int>dp(amount+1,INT_MAX);
        dp[0]=0;
        for(int coin: coins)
        {
            for(int i=1;i<=amount;i++)
            {
                if(i>=coin&&dp[i-coin]!=INT_MAX)
                {
                    dp[i]=min(dp[i],dp[i - coin]+ 1);
                }
            }
        }
        if(dp[amount]==INT_MAX)return -1;

        return dp[amount];
    }
};


JAVA SOLUTION:
class Solution {
    public int coinChange(int[] coins, int amount) {
        int dp[]=new int[amount+ 1];
        for(int i=1;i<amount+1;i++)
        {
            dp[i]=Integer.MAX_VALUE;
        }
        for(int coin:coins)
        {
            for(int i=1;i<=amount;i++)
            {
                if(i>=coin&&dp[i - coin]!=Integer.MAX_VALUE)
                {
                    dp[i]=Math.min(dp[i],dp[i - coin]+ 1);
                }
            }
        }
        if(dp[amount]==Integer.MAX_VALUE)return -1;
        return dp[amount];
    }
}


EXPLAINATION:

=========================================================
COIN CHANGE PROBLEM USING DYNAMIC PROGRAMMING
=========================================================

1. PROBLEM STATEMENT
--------------------

Given a set of coin denominations and a target amount,
find the MINIMUM number of coins required to make that amount.

Each coin can be used any number of times.

Example

Coins = {1, 2, 5}
Amount = 11

Answer = 3

Explanation

11 = 5 + 5 + 1


=========================================================
2. MAIN IDEA
=========================================================

Suppose someone asks,

"How many minimum coins are needed to make Rs.11?"

Instead of solving 11 directly, think like this:

Can I reach 11 by using one more coin from a smaller amount?

11 can come from

10 + 1
9 + 2
6 + 5

So,

If I already know the minimum coins needed for

10
9
6

then I can easily find the answer for 11.

This is exactly what Dynamic Programming does.

It solves smaller problems first and stores their answers.

=========================================================

If we already know the shortest way to reach

then reaching 11 becomes easy.

There is no need to solve everything again.

=========================================================
6. HOW DP THINKS
=========================================================

Suppose we want amount = 8

DP asks

"If I use one coin first,
what amount remains?"


Using coin 1

8 -> 7

Using coin 2

8 -> 6

Using coin 5

8 -> 3


It already knows

Minimum coins for

7
6
3

So it simply adds one more coin and chooses
the smallest answer.


=========================================================
7. WHY IS THIS DYNAMIC PROGRAMMING?
=========================================================

Property 1

Optimal Substructure

The best answer for

11

depends on the best answers for

10
9
6


Property 2

Overlapping Subproblems

While solving

11

we repeatedly need

10
9
8
7
6

Instead of solving them repeatedly,

Dynamic Programming stores them once
and reuses them.


=========================================================
8. MEMORY TRICK
=========================================================

Think of every amount as a stair.

Every coin is a jump.

Your goal is to reach the final stair
using the fewest jumps possible.

Dynamic Programming remembers the shortest
way to reach every previous stair, so it never
calculates the same thing twice.


=========================================================
9. ONE-LINE SUMMARY
=========================================================

To find the minimum coins for amount X,
try every coin once, look at the best answer
for the remaining amount (X - coin),
add one coin, and choose the minimum.
