Given a non-empty array of integers nums, every element appears twice except for one. Find that single one.

You must implement a solution with a linear runtime complexity and use only constant extra space.

 

Example 1:

Input: nums = [2,2,1]

Output: 1

Example 2:

Input: nums = [4,1,2,1,2]

Output: 4

Example 3:

Input: nums = [1]

Output: 1
JAVA SOLUTION:
class Solution {
    public int singleNumber(int[] nums) {
        int result = 0;
        for (int num : nums) {
            result ^= num; 
        }
        return result;
    }
}

C++SOLUTION:
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        int res=0;
        for(int num:nums)
        {
            res^=num;
        }
        return res;
    }
};

EXPLAINATION:
By applying the Bitwise XOR operator (^), pairs of identical numbers perfectly cancel each other out (a ^ a = 0 and a ^ 0 = a). 
This isolates the single remaining number in exactly one pass with constant extra space.
et's look at the array [4, 1, 2, 1, 2]:

Your loop essentially does this: 0 ^ 4 ^ 1 ^ 2 ^ 1 ^ 2

Because order doesn't matter, the computer treats it like this: 4 ^ (1 ^ 1) ^ (2 ^ 2)

The pairs cancel into zeros: 4 ^ 0 ^ 0

You are left with just 4, which is the single number.

By doing this, you instantly isolate the single number in one quick pass without needing to sort the array or use extra memory.
